# 开发日志 — 2026-07-10 — 任务管理增强

## 任务管理增强

### 新增功能

任务管理页面（`/tasks`）从基础的列表展示升级为完整的任务管理控制台：

1. **状态筛选 Pills**：全部 / 等待中 / 下载中 / 已完成 / 失败，每个 Pill 显示对应数量。

2. **关键词搜索**：支持按标题、URL、M3U8 URL 模糊搜索，实时过滤。

3. **排序**：最新优先 / 最早优先 / 进度降序 / 进度升序 / 按状态（下载中 → 等待中 → 暂停 → 转码 → 失败 → 取消 → 完成）。

4. **批量选择与操作**：
   - 表头全选/取消全选
   - 单行勾选
   - 批量开始 / 批量暂停 / 批量取消 / 批量删除
   - 选中行高亮显示

5. **状态持久化**：筛选条件、搜索关键词、排序方式、展开的任务 ID 通过 `useRouteState` 持久化到 `sessionStorage`，页面切换后恢复。

6. **元信息展示**：任务详情展开面板新增显示分类（Categories）和导演/系列（Director）。

### 实现细节

- 使用 `useMemo` 缓存 `statusCounts` 和 `filteredTasks`，避免每次渲染重新计算。
- `FILTER_PILLS`、`SORT_OPTIONS`、`STATUS_ORDER` 作为模块级常量，避免重复创建。
- `handleAction` 和 `handleBatchAction` 使用 `useCallback` 稳定化。
- 批量操作使用 `Set<number>` 管理选中 ID，支持 O(1) 查找/添加/删除。
- 空状态区分「无任务」和「无匹配结果」两种场景，提供不同提示文案。
